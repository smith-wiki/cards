# Mintlify as a hosted publishing option

Checked September 29, 2026; documented capabilities, not a tested deployment.

The [search MCP documentation](https://www.mintlify.com/docs/ai/model-context-protocol) describes anonymous access to public indexed pages and tools for search and document navigation/reading. Pages outside navigation need explicit indexing configuration; ignored files remain excluded.

[Multi-repository projects](https://www.mintlify.com/docs/deploy/multi-repo) combine sources into one site. They require Enterprise, a docs.json in each source, and a shared Git provider.

My assessment: a candidate when publishing the corpus as a documentation site is acceptable, not a drop-in promise to index every Markdown file.
