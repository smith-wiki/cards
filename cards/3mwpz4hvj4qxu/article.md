# Decisions API: bounded choices in an agent workflow

Developers define questions and a finite set of answers, then supply text or image context. The returned answers can classify content, route a request, or select an agent's next action.

Illustrative question: should this task use a tool, request clarification, or finish? The application would still define what each choice permits.

At the September 29 announcement, access was a limited preview, with a broader release planned in the coming days.
