# Open source and an installable software product are not opposites

Reviewed September 29, 2026. OpenShell supplies executable software and deployment tooling, not only a policy proposal. Its repository documents an installer, a local gateway, SDKs, container-based deployment, and an Apache-2.0 license. The default image contains no agent: users bring or install the workload. The repository also provides an AS IS disclaimer and community issue and discussion channels.

Source: [OpenShell repository](https://github.com/NVIDIA/OpenShell).

The current support matrix assigns qualified stable builds to production use on listed configurations, distinguishes experimental interfaces, and documents a maintenance policy. This is a release-engineering commitment; it does not establish a separately purchased service-level agreement or a hosted fleet-management service.

Source: [support matrix](https://docs.nvidia.com/openshell/latest/about/support-matrix).

This confirms the narrower [earlier release-status finding](card:3mwlwqxodu7mc). Do not transfer that status to every Sentry or partner deployment.
