# Plugin Extensions: an interface alongside the conversation

Plugins can offer a fullscreen sidebar app, a conversation panel, custom file viewers/editors, settings, deep links, and bidirectional context sharing between the model and the MCP App.

Proposal for Smith Wiki: show the card tree and selected card next to the conversation, with navigation informing the discussion. This requires building an extension; OpenAI has not announced a Smith Wiki interface.

The detailed guide says web extensions for Free and Go are coming soon, despite the recap's broader availability statement. Composer mentions currently require the desktop app.

[Official extension guide](https://developers.openai.com/plugins/build/extensions).
