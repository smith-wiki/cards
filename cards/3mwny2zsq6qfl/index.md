Central onboarding maps one stable agent identity to a distinct chat account, credentials, room grants, and an execution profile. AX does not provision chat accounts. Buzz uses one Nostr keypair per bot; Mattermost has a bot API, Slack app manifests, and Zulip native bot accounts.
