# ChatGPT plan usage in other tools

Participating applications can offer sign-in and a separate choice to use eligible ChatGPT plan allowance. Plus and Pro users can set a weekly cap per application; these caps share the overall allowance rather than creating extra usage.

The DevDay recap names OpenClaw among the partners. This is relevant when comparing personal-agent runtimes: supported subscription access becomes part of the choice.

Applications may still charge separately. Plan sharing does not itself grant access to ChatGPT conversations or memories. It does not provide unlimited general-purpose API access.

Sources: [Plan usage guide](https://help.openai.com/en/articles/20001542-using-your-chatgpt-plan-in-other-apps-and-sites), [DevDay partner announcement](https://openai.com/index/devday-2026-recap/).
