For learning OpenShell, start with its local Docker, Podman, or MicroVM quickstart, then move a real workload to k3s. NVIDIA currently marks the Kubernetes Helm path experimental and says not to use it in production, so k3s is a second-stage integration test, not the simplest introduction.
