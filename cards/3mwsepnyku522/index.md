  text: "How does AG-UI relate to MCP?"

MCP connects an agent to tools and data; AG-UI connects its execution to a user-facing app. Existing MCP servers can stay behind the agent. MCP also supports input requests and progress, while MCP Apps embeds tool interfaces in a host; AG-UI covers the agent-app run.
