# Ecosystem participation is not a connector contract

The launch illustration explicitly spans applications, models, infrastructure, chips, and energy. These companies do not all connect to OpenShell in the same way.

NVIDIA's launch announcement describes several different relationships: SAP is embedding OpenShell in Joule Studio runtime; Scale AI is incorporating platform technology into its agent infrastructure; infrastructure vendors support deployments; other organizations are users or collaborators. Those descriptions establish different scopes, not one common plug-in mechanism or a guarantee of general availability.

HP's own announcement uses future-oriented language about incorporating the technology into its AI infrastructure. It is not a guide for connecting an HP tool to an agent.

For adoption, evaluate each claimed integration separately: which component connects, which documented interface it uses, what functionality exists today, and which release and deployment conditions apply. Do not infer these from the logo wall.
