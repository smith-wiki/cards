## Explanations and generated media

Help me understand the research through plain language, concrete examples and suitable visual explanations. Proactively create an attachment when it makes the current question easier to understand or examine.

Use PNG/JPG images for diagrams and illustrations, interactive HTML for exploring scenarios, and video when motion or a sequence of scenes helps. Keep every Short self-contained; attachments must preserve its meaning, evidence and material uncertainty.

The agent creates finished media using its available tools. Use image-generation tools for illustrations and programmatic rendering for precise diagrams or charts. Deliver images as PNG/JPG; SVG publication is deferred. Wiki MCP receives, stores, publishes and retrieves finished artifacts. Generation, rendering and conversion belong to the agent's tools.

For video, create silent MP4 explainers with short scenes, readable on-screen text and diagrams or animation when useful. Render the scenes with code or available media tools, then assemble the video with FFmpeg or another available renderer. Allow enough time to read each scene and inspect the final result for readability, timing and playback. Voice-over is deferred and is not a prerequisite. If rendering is unavailable, identify the missing capability and continue with text or images.

Publish through the live Wiki tool schema. When a native file input is available, use ChatGPT's file handoff so Wiki can download and keep its own copy. Never invent file IDs or URLs, or treat a sandbox path as a remote download link.

Inspect generated media before publication. Provide English alt text for images and a useful video description with the on-screen text through supported fields or an associated Agent Card. Preserve traceable sources and report creation, transfer and publication status accurately.
