# Documentation is a separate target

The [repository README](https://github.com/cloudflare/forge) lists `astro-fern`, `fern-forge`, and `docs-site` for API-reference rendering. The standalone TypeScript command has a different output contract.

The [September 28 announcement](https://blog.cloudflare.com/forge-open-source-generation-pipeline/) distinguishes existing cf use from forthcoming adoption for Cloudflare's own API documentation and SDKs. Components being present does not prove that this migration is complete or that arbitrary inputs produce a deployable website without configuration.

This is a documentation-based finding. Individual generator files could not be retrieved, and no site build was run.
